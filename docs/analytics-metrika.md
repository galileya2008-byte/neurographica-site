# Яндекс.Метрика: цели на сайте

Счётчик подключён в `app/layout.tsx` (ID в `config/analytics.ts`).

## Создайте цели в интерфейсе Метрики

Для каждой строки: **Настройки → Цели → Добавить цель → JavaScript-событие**  
В поле **«Идентификатор цели»** вставьте значение **точно** как ниже (латиница, без пробелов).

| Идентификатор       | Когда срабатывает на сайте                          |
|---------------------|-----------------------------------------------------|
| `purchase_click`    | Клик «Купить», оплата GetCourse / neirogalina.ru   |
| `telegram_click`    | Ссылка на Telegram                                  |
| `email_click`       | mailto: и кнопки «Написать на email»                |
| `cta_masterclasses` | CTA на каталог мастер-классов (главная, шапка и т.д.) |
| `cta_programs`      | CTA «Программы» на главной                          |
| `cta_contacts`      | CTA «Контакты» на главной                           |

Для `purchase_click` в отчётах можно смотреть параметр **`product`** (slug программы или мастер-класса).

## Проверка

1. Откройте сайт в режиме инкognito.
2. Метрика → **Отчёты → Конверсии** или **Цели** (после настройки целей).
3. Нажмите тестовую кнопку оплаты — в течение нескольких минут должно появиться достижение цели.
