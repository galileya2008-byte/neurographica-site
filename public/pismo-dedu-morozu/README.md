# Интерактив «Письмо Деду Морозу» — отдельная страница для вашего сайта

## Что в папке

- `pismo.html` — весь интерактив одним файлом (тест, письмо, сургучная печать, снег, музыка, скачивание письма картинкой, кнопка покупки).
- `pismo_dedu_morozu_music.mp3` — новогодняя музыкальная подложка.

## Как добавить на сайт (GitHub Pages)

1. Загрузите **оба файла** в репозиторий вашего сайта — в одну папку, рядом друг с другом (например, в корень или в папку `pismo/`).
2. Страница будет доступна по адресу вида:
   - `https://siteneirogalina.ru/pismo.html` (если файлы в корне)
   - `https://siteneirogalina.ru/pismo/pismo.html` (если в папке `pismo/`)
3. Имя `pismo.html` можно переименовать как угодно (например, `novogodnee-pismo.html`) — главное, чтобы музыкальный файл лежал рядом и не переименовывался.

## Важно

- Файлы должны лежать рядом: страница ищет музыку по имени `pismo_dedu_morozu_music.mp3` в своей папке.
- Кнопка «Хочу на занятие» ведёт на https://neirogalina.ru/novogodnee-pismo-urok
- Статистика прохождений (начали тест, запечатали письмо, нажали на покупку) продолжает писаться в вашу админку в Lovable — она общая для обеих версий.
- Музыка включается только по кнопке «Включить музыку» — автозапуска нет.
